# leemeii 个人主页设计规格

## 目标

在 `leemeii.github.io` 构建一个可直接由 GitHub Pages 托管的单页个人主页。页面以现有荣誉总表为唯一内容事实来源，突出软件测试、静态分析、向量数据库与智能代码生成方向，同时准确区分已获荣誉、进行中项目和投稿论文。

## 内容原则

- 对外身份统一使用 `leemeii`，不推测或公开真实姓名、邮箱、专业名称等未提供信息。
- 页面、源码注释、元数据和页脚不出现 ChatGPT、OpenAI 或生成工具品牌。
- 论文统一使用 `Submitted` 或 `Under Review` 语义，不暗示录用。
- 不公开证明材料目录、评审分数、证书编号或其他隐私数据。
- 没有公开链接的成果不渲染虚假按钮；当前唯一外部个人链接为 `https://github.com/leemeii`。
- 资料中未给出的精确项目名、比赛组别和成绩直接省略，不使用占位符。

## 信息架构

页面采用单页锚点导航，包含以下区域：

1. `首页 / Home`：品牌名、身份概述、研究宣言、核心数据和 GitHub 入口。
2. `关于 / About`：简短个人介绍、当前关注方向和研究关键词。
3. `研究 / Research`：三条研究主线、三篇投稿论文、静态分析开源贡献和国家级大创经历。
4. `荣誉 / Honors`：按学业、科研、竞赛、实践四类整理现有记录，保留年份和角色。
5. `足迹 / Journey`：以 2025 与 2026 两个年度节点概括成长轨迹。
6. `联系 / Contact`：GitHub 链接与简短合作邀请。

## 视觉方向

整体采用“现代研究手记”风格，而非套用常见科技渐变模板：

- 暖象牙纸色为主背景，墨绿色作为主色，朱砂红作为少量强调色。
- 大标题使用中文衬线字体，正文使用清爽黑体；英文标签采用窄字距全大写。
- 首屏采用不对称双栏布局，右侧以 `LM` 字母肖像、坐标线和研究关键词形成独特识别。
- 内容区域使用细线、编号、时间轴与留白，而不是大量浮动圆角卡片。
- 深色主题延续纸张与墨色概念，并通过主题按钮切换；用户选择保存在浏览器本地。
- 首屏内容进行有节奏的 CSS 入场动画；尊重 `prefers-reduced-motion`。

## 页面行为

- 桌面端使用顶部粘性导航；移动端导航可横向滚动，不依赖脚本菜单。
- 点击页内导航平滑滚动到对应区域，并为键盘用户提供跳转到正文的链接。
- 主题切换按钮在浅色和深色之间切换，初始状态优先读取已保存偏好，其次读取系统主题。
- 所有外部链接在新标签页打开，并带有安全的 `rel` 属性。
- 页面在 360px、768px、1440px 常见视口下保持可读且无横向溢出。

## 技术结构

- `index.html`：语义化页面、内容和元数据。
- `assets/css/styles.css`：设计系统、布局、响应式、主题和动画。
- `assets/js/main.js`：纯函数形式的主题解析、切换与初始化。
- `tests/site.test.mjs`：使用 Node 内置测试器验证页面结构、内容边界、链接和主题逻辑。
- `package.json`：仅提供测试命令，不引入运行时或构建依赖。

## 验收标准

- 根目录直接打开 `index.html` 可用，并可由 GitHub Pages 无构建发布。
- 首页完整呈现现有资料中的核心学业、科研、竞赛与实践成果。
- 所有投稿论文均有明确投稿状态，页面不包含未经提供的个人信息。
- 页面和源码不出现被禁止的品牌字符串。
- 键盘焦点、颜色对比、语义标题、主题按钮标签与减少动画偏好符合基础无障碍要求。
- Node 测试全部通过，HTML 内部锚点无缺失。
